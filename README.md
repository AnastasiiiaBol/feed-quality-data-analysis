# Применение методов анализа данных для определения факторов, влияющих на качество консервированных кормов растительного происхождения

В данном репозитории представлены материалы дипломного проекта по теме:
«Применение методов анализа данных для определения факторов, влияющих на качество консервированных кормов растительного происхождения».

## Описание проекта

Цель проекта заключается в применении методов анализа данных для определения факторов, связанных с качеством консервированных кормов растительного происхождения.

В рамках работы выполнялись:

* загрузка и предварительная обработка исходных данных;
* проверка структуры загруженной таблицы;
* очистка числовых значений и заполнение пропусков;
* расчёт описательной статистики;
* построение корреляционной матрицы;
* построение SEM/path-модели факторов качества кормов;
* расчёт коэффициентов модели, R² и индексов качества модели;
* визуализация структурных связей между показателями;
* формирование итогового аналитического заключения;
* выгрузка результатов анализа в Excel-отчёт.

## Состав репозитория

Ниже перечислены файлы, используемые в рамках дипломного проекта:

* `app.R` — основной файл Shiny-приложения, содержащий код пользовательского интерфейса, загрузки данных, предобработки, расчёта статистических показателей, построения SEM/path-модели, визуализации результатов и формирования итогового заключения.
* `sem_graph_github_clean.R` — R-скрипт для построения SEM/path-модели и графической схемы структурных связей между показателями состава корма, брожения, питательности и экспертной оценки качества.
* `Силосразн.xlsx` — исходная база данных лабораторных показателей качества консервированных кормов растительного происхождения.
* `README.md` — описание проекта, состава файлов и порядка запуска программной реализации.

## Запуск приложения

Для запуска приложения необходимо открыть файл `app.R` в RStudio и выполнить команду:

```r
shiny::runApp("app.R")
```

Также приложение можно запустить нажатием кнопки **Run App** в RStudio.

После запуска приложения пользователь загружает Excel-файл с данными, нажимает кнопку **«Запустить анализ»** и получает результаты во вкладках интерфейса.

## Работа с LLM-модулем

В приложении предусмотрен дополнительный модуль формирования текстового заключения с использованием OpenRouter. Данный модуль не пересчитывает статистические показатели, а только формирует текстовую интерпретацию уже рассчитанных результатов SEM/path-модели.

Для использования LLM-модуля необходимо указать API-ключ OpenRouter во вкладке приложения или задать его через переменную окружения:

```r
Sys.setenv(OPENROUTER_API_KEY = "your_api_key")
```

API-ключ не хранится в исходном коде приложения.

## Результаты работы приложения

Приложение позволяет получить:

* таблицу проверки структуры данных;
* описательную статистику показателей качества;
* корреляционную матрицу Спирмена;
* таблицу коэффициентов SEM/path-модели;
* коэффициенты детерминации зависимых переменных;
* индексы качества модели;
* графическую схему SEM/path-модели;
* автоматическое итоговое заключение;
* LLM-заключение по результатам анализа;
* Excel-отчёт с основными результатами анализа.

## Назначение проекта

Разработанная информационная система предназначена для автоматизации анализа лабораторных данных о качестве консервированных кормов растительного происхождения. Она позволяет использовать предложенную методику не как разовый расчёт, а как воспроизводимый инструмент для обработки обновляемой базы данных.
