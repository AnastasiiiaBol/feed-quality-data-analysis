# Применение методов анализа данных для определения факторов, влияющих на качество консервированных кормов растительного происхождения

В данном репозитории представлен программный код, разработанный в рамках производственной практики по теме:  
«Применение методов анализа данных для определения факторов, влияющих на качество консервированных кормов растительного происхождения».

## Описание проекта

Цель проекта заключается в применении методов анализа данных и машинного обучения для исследования факторов, влияющих на качество консервированных кормов растительного происхождения.

В рамках работы выполнялись:

- загрузка и предварительная обработка исходных данных;
- расчёт дополнительных показателей;
- разведочный анализ данных;
- построение корреляционной матрицы;
- сравнение групп силоса по основным показателям;
- построение регрессионных моделей;
- построение моделей машинного обучения для диагностики качества корма;
- сравнение результатов с нормативными и формальными методами оценки;
- формирование итогового аналитического резюме.

## Состав репозитория

- `silos.py` — основной программный файл проекта, содержащий код обработки данных, анализа, построения моделей и вывода результатов.

## Используемые технологии

В проекте использовались:
